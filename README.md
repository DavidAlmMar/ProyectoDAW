# GPE
Aplicación web de gestión de plazas para eventos pequeños.

Pretende resolver el problema que presentan algunos eventos que necesitan obtener ciertos datos específicos de las personas que se inscriben, y que normalmente necesitan utilizar herramientas externas o crear las suyas propias para suplir esta carencia.
Y la idea de la pagina web es permitir la obtención de dicha información en el momento en el que se realiza la reserva.

La aplicación web deberá de permitir a los organizadores de eventos poder crear todas las áreas de reserva con las preguntas que necesiten para todos lo eventos que quieran.
También deberá de permitir que los organizadores puedan acceder y extraer la información obtenida por su área de reserva.
El publico deberá de poder inscribirse en los eventos que quieran y obtener el correo con la confirmación y el QR o código que precise el evento.

Actualmente se encuentra en la planificación de la ejecución

La documentación del proyecto se encontrara en el directorio docs/ de este repositorio.
